# 页间 · Between Pages

围绕原创人物的本地 AI 故事创作桌面应用。文字与插画模型由作者自行配置，支持 Windows 便携版。

## 工作台

- **世界与人物**集中保存人物、世界规则、叙事偏好、分区要点和设定参考图。从创作资料库引入的资料是独立只读副本。
- **故事蓝图**是唯一规划来源，包含自由分区、总纲、卷纲、章纲与场景细纲。保存立即生效，蓝图优先于世界与人物。
- **自由探索**围绕当前处境和近期方向创作，允许留白；**长篇创作**按需使用分层规划。切换模式保留全部内容，对话与工具流程各自适配。
- **灵感脑暴**基于本书非正文资料聊天，只保存聊天记录。
- **AI 提炼**在资料编辑中将上传文档整理为概述、规则与分区要点，检查后保存，原始文档不入库。**完善蓝图**产生蓝图候选，组与单条内容可折叠，数量不自动截断。
- **创作工具**可直接选择文字模型，优先于职责与默认模型，并记住当前作品与模式的选择。
- **正文写作**中，开篇只写空章，续写只追加文末。**文段打磨**完整参考当前章，只替换编辑器选区。
- **故事检查**按连续性、节奏或人物弧线输出报告，展示引用、位置、影响、建议和实际覆盖范围，不写入故事。
- **记忆整理**从已采用正文提取事实并保留章节与版本来源。
- 创作工具的 AI 写入统一显示红色删除、绿色新增，可编辑建议后按完整目标审核。采用前保存快照，过期、跨故事、重复采用和中断结果不能写入。资料提炼先填入编辑表单，由作者检查并保存。
- 请求预览展示实际文字、参考图片、来源、优先级与省略范围。全部有效基础资料完整注入；图片真实发送，封面不自动发送。资料超限或模型不支持图片时明确阻止。

支持独立资料库、TXT／Markdown 导入、章节快照、正文导出、故事封面、参考图生图、主题与字号设置，以及本地 ZIP 备份和数据目录迁移。

## 使用与开发

推荐 Node.js 24 LTS、npm、PowerShell 7。

```powershell
npm ci
npm run dev
```

进入设置 → 模型设置，填写接口与 API Key，选择模型，并按服务商说明配置上下文预算和图片输入能力。设定与蓝图均可留空，从一个空章开始写作。

```powershell
npm test
npm run typecheck
npm run build
node scripts/qa-workspace.mjs   # 独立数据库及模拟模型的界面验收
npm run pack:win
npm run dist:win
```

本轮重构使用新的领域数据库格式，不迁移旧开发数据。可设置 STORYBOOK_DATA_DIR 为新的空目录隔离开发与个人数据。默认数据目录是程序旁的 data/；运行缓存在 runtime/，数据库在 database/，图片在 assets/。完整备份包含数据库和素材；恢复时使用同一份备份，彻底退出程序后操作。

API Key 保存在本地数据库，随备份保存。执行 AI 时，实际预览所示资料与图片会发送到配置的服务；单纯编辑或导入文件不会调用模型。

详细规则见 [创作说明](docs/CREATION.md)，开发与测试见 [开发说明](docs/DEVELOPMENT.md)，存储说明见 [数据存储](docs/STORAGE.md)。
