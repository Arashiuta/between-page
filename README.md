# 页间 · Between Pages

围绕 OC 的个人故事创作工作台。Windows 桌面应用，支持自由探索与长篇创作、可编辑故事蓝图、逐章写作、版本和记忆管理，以及自配接口生成插画。

## 开发与打包

推荐 Node.js 24、PowerShell 7。

```powershell
npm install
npm run dev
```

```powershell
npm run typecheck
npm test
npm run build
npm run pack:win  # release/win-unpacked/页间.exe
npm run dist:win  # 便携 ZIP
```

SQLite 使用 Electron / Node 自带的 `node:sqlite`，无额外原生模块构建步骤。自动化测试在 Node.js 24 上执行。

## 使用

1. 在「设置与模型」分别填写文字和生图服务的地址、Key，点击「获取模型列表」，勾选模型并选择默认项。接口、Key、模型勾选和默认项均自动保存，切换页面或退出软件前会完成保存。Key 在输入框中回填，删除全部内容即保存为空；不需要清除选项。点击「测试模型连通性」验证文字服务。列表来自兼容的 GET /models；不支持列表的服务可手动添加模型名称。创作区可切换已勾选模型。支持基础地址与完整端点。文字使用兼容 chat/completions 的接口；生图使用 images/generations，携带参考图时使用 images/edits。
2. 在「创作资料」添加 OC、世界观或灵感。支持概述、固定设定与自由分区，以及 TXT / MD / Markdown 多文档导入。原文可直接保存，也可点击「AI 整理文档」提取可编辑草稿；核对来源与待确认项后，再选择追加或替换。只有点击整理才会请求模型。新建故事时复制资料和原文，每个故事的修改互相独立。
3. 打开故事，编辑计划与正文。右侧「AI 创作」支持正文、大纲、方向调整、选段改写、检查和插画提示词。生成内容先保存在独立草稿区，由作者决定写入。
4. 满意后「采用当前章节」，再选择「整理正式记忆」。未采用草稿不进入正式记忆。修改早期采用章节会停用相关及后续自动记忆，后续采用章节标记待复核。
5. 在「故事插画」手动生成图片，支持 OC 参考图。图片不会反向改变故事事实。生成结果保存到本地，支持导出和保留多个版本。
6. 在「AI 职责」查看和编辑设定策划、剧情规划、正文写作、走向调整、文段改写、连续性检查、记忆整理、插画构思、资料整理的工作要求；可指定不同文字模型，或留空跟随当前文字模型。共用要求和软件附加的 JSON 格式均可查看。修改后点击「保存职责设置」。

创作区的「查看职责与本次参考内容」可查看完整系统提示词、实际参考上下文与资料覆盖情况。固定设定和标记为「始终参考」的分区完整装入；其余分区及启用的原文按相关性选取，资料部分预算为 48000 字，超出的固定内容会明确报错。原文在本地完整保存，单文件上限 20 万字 / 2 MB，单条资料最多 12 份原文、50 个分区、合计 40 万字。一次 AI 整理输入上限 6 万字，超限需分批勾选文档，不会静默截断。

生图默认模型为 `gpt-image-2`，允许修改为服务商要求的别名。尺寸、质量与参考图功能需要服务实际支持。参考图使用 multipart `image[]`。图像一致性取决于模型、参考图和提示词。应用不预置任何真实 Key，接口测试会实际请求文字模型，生图仅在点击按钮后请求。

## 数据目录

开发时默认使用项目的 `data/`；打包后默认使用可执行文件旁的 `data/`。请解压到有写入权限的目录。

```text
data/
  database/storybook.sqlite  正式数据、草稿、版本、设定、记忆、模型配置与明文 Key
  assets/                   参考图与生成图片
  settings/                 预留配置目录
  backups/                  完整备份 ZIP
  exports/                  默认导出目录
  runtime/                  Electron 缓存和日志
```

应用使用 SQLite WAL。手动复制整个 data 前先退出软件；也可以在设置里生成运行中的一致性备份。恢复备份时先退出，保留旧数据副本，将 ZIP 中的 database 与 assets 放回 data。存在旧数据库的 `-wal`、`-shm` 文件时，不要将它们与其他快照混用；建议将当前 data 整体改名保存后，在新的 data 目录恢复。

更换目录会将一致的数据库快照和图片等资料复制到一个空目录，写入程序旁的 `data-location.json` 后重启，原目录保留。移动软件且使用自选目录时，需要一起保留此定位文件并确保目标路径有效。API Key 明文保存在本地数据库中，完整备份会一起包含。旧版加密 Key 会在原 Windows 账户下首次读取时自动迁移为明文；旧 Key 无法解密时保留原记录，可重新填写。

## 当前边界

- 已实现基础关键词和近期记忆选择，不要求向量模型。
- 蓝图修改是创作计划；既有正文的连续性由检查功能辅助复核，不会自动重写整本故事。
- 暂不包含云同步、复杂分支树、无人值守整本生成或模型自动切换。
- 官方文档在当前开发网络返回 403，兼容请求通过本地模拟服务验证；实际模型效果和供应商扩展字段需要用自己的服务验证。

## 结构

`src/main`：数据、接口、文件、密钥、IPC；`src/preload`：最小桌面桥；`src/renderer`：Vue 创作界面；`src/shared`：类型和文档转换；`tests`：正式记忆、版本隔离、接口兼容等回归测试。
