# 页间 · Between Pages

围绕原创人物的本地 AI 故事创作桌面应用。文字与插画模型由作者自行配置，支持 Windows 便携版。

## 工作台

- **世界与人物**按页签分别展示人物、世界资料和灵感资料，叙事偏好单独保存。世界规则可作为世界资料添加；从创作资料库引入的资料是独立只读副本。
- **额外设定**使用自定义条目约束故事，两种模式全程参考；额外设定优先于世界与人物。
- **长篇创作**提供独立的树形“大纲规划”页，支持总纲、卷纲、章纲、场景细纲与关联正文，手工或 AI 完善后按纲写作，各层可留空。
- **自由探索**在开篇审核写入后自动生成下一章走向，续写后可手动生成走向；默认 3 个，设置中可选 1—5 个。走向可编辑或自定，一键创建下一章并生成待审核正文。
- 切换模式保留全部内容；自由探索暂停参考大纲。全部额外设定、引入资料和适用的有效故事记忆持续参与创作，未选走向与未来规划不属于已发生事实。
- **灵感脑暴**基于本书非正文资料聊天。创作对话默认只留在本次应用运行期间，需手动保存后才进入“已保存”；已保存对话可继续、重命名或删除。
- **AI 提炼**在资料编辑中将上传文档整理为概述、规则与分区要点，检查后保存，原始文档不入库。**完善额外设定**产生额外设定候选，组与单条内容可折叠，数量不自动截断。
- **创作工具**可直接选择文字模型，优先于职责与默认模型，并记住当前作品与模式的选择。
- **正文写作**中，开篇只写空章，续写只在本章末尾追加，扩写生成完整章节替换稿并经审核写入。**文段打磨**完整参考当前章，只替换编辑器选区。
- **故事检查**按连续性、节奏或人物弧线输出报告，展示引用、位置、影响、建议和实际覆盖范围，不写入故事。
- 正文页的**故事记忆**可多选已采用且已复核的章节逐章提取摘要，也可调优启用记忆中的冲突、后续覆盖和闭环伏笔。候选经审核后才新增、替换或停用；手工记忆保持启用并标注冲突，来源版本变化时拒绝采用。
- 创作工具提供“创作”和“已保存”页签；结果支持放大阅读。
- 创作工具的 AI 写入统一显示红色删除、绿色新增，可编辑建议后按完整目标审核。采用前保存快照，过期、跨故事、重复采用和中断结果不能写入。资料提炼先填入编辑表单，由作者检查并保存。
- 请求预览展示实际文字、参考图片、来源、优先级与省略范围。全部有效基础资料完整注入；图片真实发送，封面不自动发送。资料超限或模型不支持图片时明确阻止。

支持独立资料库、TXT／Markdown 导入、章节快照、正文导出、故事封面、参考图生图、主题与字号设置，以及本地 ZIP 备份和数据目录迁移。

## 使用与开发

推荐 Node.js 24 LTS、npm、PowerShell 7。

```powershell
npm ci
npm run dev
```

进入设置 → 模型设置，填写接口与 API Key，选择模型，并按服务商说明配置上下文预算和图片输入能力。设定与额外设定均可留空，从一个空章开始写作。

```powershell
npm test
npm run typecheck
npm run build
node scripts/qa-workspace.mjs   # 独立数据库及模拟模型的界面验收
npm run pack:win
npm run dist:win
```

本次大纲与探索更新沿用现有版本 2 数据库，保留额外设定、大纲节点 ID、正文和章节关联，无需清空数据。开发验收可设置 STORYBOOK_DATA_DIR 为新的空目录隔离个人数据。默认数据目录是程序旁的 data/；运行缓存在 runtime/，数据库在 database/，图片在 assets/。完整备份包含数据库和素材；恢复时使用同一份备份，彻底退出程序后操作。

API Key 保存在本地数据库，随备份保存。执行 AI 时，实际预览所示资料与图片会发送到配置的服务；单纯编辑或导入文件不会调用模型。

详细规则见 [创作说明](docs/CREATION.md)，开发与测试见 [开发说明](docs/DEVELOPMENT.md)，存储说明见 [数据存储](docs/STORAGE.md)。
