## 0.2.0 · 2026-11-04

- 创作资料增加自由分区、固定规则与「始终参考」标记，旧版资料自动兼容；支持多份 TXT / MD / Markdown 导入，完整保留原文。支持 UTF-8、带 BOM 的 UTF-16 及常见 GBK 文本。
- 新增「AI 整理文档」，模型输出先作为可编辑草稿，标注分区来源与待确认项；由作者选择追加或替换，应用后仍需保存。原文和参考图保留，故事副本互相独立。
- 增加「AI 职责」页面，展示并编辑九项职责的详细工作要求、共用提示词与独立模型；记忆和资料整理的必要 JSON 协议可直接查看。创作区显示当前职责并可查看实际系统提示词、参考内容与资料覆盖情况。
- 移除旧版资料描述前 3500 字、约束前 1500 字的直接截断。固定规则与始终参考的分区完整优先装入，其他资料采用段落关键词排序；超过预算时可查看省略情况，必要规则超限明确报错。无需向量模型。
- 修复进度消息晚于最终结果到达时重复追加正文的问题。
- 39 项自动化测试、类型检查和生产构建通过。涵盖原文编码与长度、整理草稿应用、来源验证、长资料尾部引用、必选资料预算、旧资料兼容、故事副本隔离、职责保存生效及迟到进度事件。
- 使用独立 `.qa/data-020/` 和本地模拟接口，桌面验证两份作者提供的 TXT 导入、草稿修改与应用、保存、复制到故事、职责提示词修改、独立模型选择、上下文预览与实际生成。数据库中两份原文逐字一致，实际请求包含两份档案末尾，使用指定模型及自定义职责。模拟整理结果仅为测试响应，不代表真实模型质量。

## 首版开发记录

2026-11-03，版本 0.1.0，临时产品名称「页间」。

## 已交付

- Windows 便携桌面应用，Vue 3 / TypeScript / Electron；暖白与鼠尾草绿的中文创作工作区。
- 自由探索、长篇创作；故事归档与恢复；独立的 OC、世界观、灵感资料库，导入故事时创建设定快照。
- 故事蓝图、世界设定、文风偏好、本章计划；Tiptap 正文编辑与本地自动保存。
- 文字模型独立配置；兼容 chat/completions、SSE 流式响应、非流式代理响应、停止生成、异常保留草稿。
- 正文生成、大纲规划、走向调整、灵感整理、选段改写、连续性检查、插画提示词等职责；生成结果由作者决定写入。
- 章节版本、采用版本、恢复前快照；正式记忆绑定采用版本和正文来源；重写早期采用章节会停用相关及后续自动记忆，标记后续采用章节待复核。
- 独立生图 URL / Key / 模型配置，默认 gpt-image-2，可修改别名；兼容生成与携带参考图的编辑接口；本地图像、提示词与章节关联；图片不会反向写入故事事实。
- EXE 旁 data 目录、系统账户加密 Key、Markdown/TXT 正文导出、图片导出、完整 ZIP 备份、数据目录迁移。
- SQLite 使用 Electron 自带的 node:sqlite，避免额外原生扩展 ABI 与编译依赖。

- TypeScript / Vue 类型检查通过。
- 20 项自动化测试通过，覆盖自动保存并发与重试、桌面 DTO 克隆、故事与版本隔离、记忆有效性、角色快照、接口协议、取消、图片输入，以及 ZIP 解压后的数据库和图片还原。
- 开发桌面实测：示例创建、配置加密保存、本地模拟服务连接、流式生成、正文追加与自动保存、采用章节、四条记忆提取及来源、图片请求和本地关联。
- Windows ZIP 打包成功；便携程序从 resources/app.asar 启动成功；首次启动空书架，使用 EXE 旁的数据目录。
- ZIP 内容核对通过，未包含开发测试 data / .qa、模拟接口配置或 Key。

## 实际边界

没有用户提供的真实模型服务或 Key，因此未进行付费文字生成或生图。兼容接口已通过本地 HTTP 服务验证，实际供应商对模型名、参考图 multipart、尺寸和质量字段的支持仍需连接后确认。官方图片文档在当前网络返回 403。

本版方向调整先输出可审阅的大纲和影响说明，由作者写入；不会自动重写整本已采用正文。向量检索、复杂分支树、无人值守批量创作、云同步和多模型分工留待后续。
