## 实际边界

没有用户提供的真实模型服务或 Key，因此未进行付费文字生成或生图。兼容接口已通过本地 HTTP 服务验证，实际供应商对模型名、参考图 multipart、尺寸和质量字段的支持仍需连接后确认。官方图片文档在当前网络返回 403。

本版方向调整先输出可审阅的大纲和影响说明，由作者写入；不会自动重写整本已采用正文。向量检索、复杂分支树、无人值守批量创作、云同步和多模型分工留待后续。
