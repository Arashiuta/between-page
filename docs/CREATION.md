# 创作模式、规划与片段

两种模式可随时在「故事蓝图与模式」切换，所有设定、旧蓝图、规划、正文、版本及独立片段保留。模式决定工作流程与规划约束；自由度决定允许补充多少细节。新建长篇默认「遵循设定」，自由探索默认「自由发挥」，切换模式不重置自由度。

## 长篇创作

默认进入作品概览，以独立功能卡片展示设定、总纲、分卷大纲、章纲、场景细纲和正文。分卷、章纲和细纲均可选；只有设定或总纲也能直接开始正常写作，不要求逐项完成。

- 设定复用故事内资料卡和自由分区，提供主要人物的动机、目标、关系及变化，以及世界规则、能力边界、势力和叙事偏好的模板。
- 总纲记录主题、核心冲突、主线、人物变化和结局方向；卷纲记录阶段目标、事件及转折；章纲记录目标、视角、冲突、变化及结束位置；细纲记录有顺序的场景行动、对白、信息释放和伏笔。
- 章纲直接使用 `Chapter.plan`，一章对应一个章纲。新增章节可留空章纲，填写时默认保存草稿，也可确认后创建；默认归入第一卷，也可选择其他分卷。默认卷纲为空，无需填写即可写作。
- 在某个层级编辑、确认或生成该项；也可指定数量生成下级规划。AI 返回可编辑、可勾选的建议，采用所选项后才更新正式规划；每项可再次单独完善或生成调整建议。
- 规划区分草拟、已确认与待核对。正文默认参考确认版本；作者可勾选使用当前规划草稿试写。旧版本已有的本章计划继续作为兼容参考。
- 确认上层变化只标记其关联下级规划和正文，显示影响来源；已有正文不自动重写，正式记忆不因规划变化失效。调整建议仍需审核采用。
- 支持保存、查看和恢复规划版本，AI 采用或恢复前保留快照。新快照包含章节顺序，恢复时同步恢复现存章节顺序，并将快照后新增的章节留在末尾；不会复活已删除章节。旧快照未记录顺序时沿用原有恢复语义。恢复不覆盖正文，对实际变化范围重新标记影响。

长篇正文请求优先加入明确设定和实际存在的可用规划，然后加入相关记忆与前文。空白或尚未确认的层级默认省略，不要求或自动生成缺失的大纲。不会把整本规划及全文无差别发送。预览提供实际系统提示词、上下文、截取与资料覆盖情况。

### 规划树与拖动

「总纲与章节规划」左侧使用分卷 → 章节 → 场景细纲的树，右侧编辑所选节点。总纲为固定入口，下方直接显示第一卷，不再显示「未分卷」分组。没有分卷的旧作品显示空白第一卷，旧未分卷章节归入第一卷，读取页面不改动原始记录、章节编号或正文。分卷和章节可展开收起，也可全部展开或收起；展开状态按故事保存，定位或新增节点时自动展开父节点。各行保留编辑、更多操作与规划状态。

- 拖动分卷前后排序时，其全部章节一同移动。章节可放在另一章之前或之后并继承其卷归属，也可拖进卷，追加到该卷末尾；空卷也可接收章节。
- 场景细纲只允许在所属章节内排序，也可使用右侧的上下移按钮。总纲不可拖动，不同层级的非法落点不会接受；插入线与分组高亮提示有效落点。
- 卷章移动按各卷及其章节同步正式章号、正文列表、AI 前文和导出。旧记录可能跨卷交错；打开页面不会整理数据，移动需要整理时先展示受影响章节及前后顺序，取消不写入。
- 移动前完成自动保存并保存规划快照，保存成功后才更新树。AI 运行或结构保存期间禁用拖动，失败保留原顺序。归属选择框和场景上下移复用同一套结构调整规则。
- 已采用章节的相对顺序变化时，沿用连续性复核与自动记忆停用规则；只改变卷归属或场景顺序时，仅标记关联规划和正文待核对。正文、采用版本和独立片段保持原内容。

「整理旧蓝图为总纲」会先显示确认框，说明使用的文字模型、材料和候选审核方式。取消不改变工具、要求或结果；确认后保存当前编辑，再生成一次总纲候选。旧蓝图保留，作者审核采用后才更新总纲。

### 列表编辑与删除

- 行内提供编辑与更多操作，章节保留右键菜单。总纲可清空；清空章纲同时移除旧确认内容，保留正文与场景细纲；删除分卷将章节归入剩余第一卷并保留顺序，没有其他分卷时显示空白第一卷。规划移除前保存快照，已确认内容的变化只标记关联范围待核对，不停用正式记忆。
- 删除整章会移除正文、版本及关联记忆，保留插画，并清理片段锚点、编入关联和失效暂存。删除独立片段及其版本不会撤回已追加到章节的内容。
- 书架可编辑作品信息、归档和恢复；彻底删除仍需先归档。资料、原始文档、分区、候选、记忆均可编辑和移除；移除候选不撤回已采用内容。自动记忆编辑后保留来源和自动失效规则。
- 图片可编辑名称和作者备注，保留原始生成信息；引用位置包括作品封面、资料卡、其他图片和撤销记录。解除引用后才能彻底删除；文件清理失败会持久化并重试。
- 正文、片段和规划快照可修改标签。快照内容只读；被当前采用记录、记忆（含停用记录）、插画、设定候选、撤销记录、工作流或暂存草稿引用的正文版本禁止单独删除。无引用快照可确认删除，当前正文或规划不受影响。

## 自由探索

默认进入正文，可直接开始、继续当前章、进入下一章、跳写片段或调整近期方向。轻量蓝图可留空，保留的长篇规划按需勾选参考，不强制预设结局。

「探索片段」适合先写结尾、后写前文或独立场景。片段复用正文编辑器、AI 写作、打磨与版本机制，可填写时间、地点、视角、衔接说明及章节参考锚点。

未编入的片段不进入正式章序、章节字数、默认正文导出或正式记忆，也不自动成为其他章节的事实。片段请求仅从指定锚点及其之前选取已采用事实，无锚点时不自行带入最新章节。未来计划和片段不能成为角色已经经历或已经知道的事实。

片段可编成指定位置的新章，保留原 ID 和全部编辑历史；也可追加到已有章节，追加前保存目标章快照，保留片段原稿并记录目标章节。再次编入会提示。编入只形成正文草稿，采用后才能整理正式记忆。

章节列表右键可前移或后移章节。改变已采用章节的事实顺序时，受影响的自动记忆停用、关联采用章节待复核；稳定前缀和手工记录保留。规划待核对与连续性待复核分别显示。

## 八个主工具

| 入口       | 内部职责与结果                             |
| ---------- | ------------------------------------------ |
| 灵感脑暴   | 发散多个可选方向，进入候选区               |
| 素材整理   | 忠实归纳、去重、识别矛盾与空白             |
| 设定与蓝图 | 人物世界分区建议、分层规划、近期走向       |
| 正文写作   | 开篇与续写，按当前模式及章节或片段选取参考 |
| 文段打磨   | 表达、场景、对白；修改建议或生成改写稿     |
| 故事检查   | 连续性、节奏、人物弧线分析                 |
| 记忆整理   | 从已采用版本提取事实，逐条审核写入         |
| 插画构思   | 为指定场景生成绘图提示词                   |

工作台和职责设置按八个入口组织，旧任务标识、模型、自定义提示词、候选和工作流记录保留。分析结果不提供正文写入按钮；规划建议进入规划节点；正文和改写稿才提供正文写入操作。

### 多轮对话与结果版本

所有文字工具都可补充要求连续迭代，每轮输出一份完整新版。展开历史轮次查看作者要求与结果，选择任意版本后可编辑、审核采用，或基于该版本继续生成；版本编号及“基于版本”标记说明分支来源，其他分支不会混入请求。

每段对话固定工具与目标章节、片段或规划节点；改写范围和结果类型也分别保存。切换工具或目标时恢复对应的最近对话，也可通过对话列表主动切换、新建、重命名或确认删除。“据此完善设定与蓝图”和“根据结果写正文”会携带所选稿件，进入目标工具的新对话。对话和版本长期存入本地数据库，切页及重启后恢复，随数据库备份保存；删除对话不会撤回已经写入的内容，也不会移除已有蓝图候选。

每版保留自己的编辑稿、生成依据和采用进度。正文仍写入草稿，再由作者确认正式章节；规划和设定逐项采用，记忆审核后写入，插画提示词进入生图入口。改写对话始终保留最初原文与选区，切回旧版不能绕过原文变化校验；记忆迭代固定来源采用版本。删除目标或来源后，历史仍可查看并显示失效原因。

每次请求结合当前故事资料和所选分支历史，历史稿件不会成为正式事实。对话历史预算为 60,000 字符，优先保留首轮要求、所选完整稿与本轮要求，再装入较近的完整问答；参考预览显示实际消息和省略轮次，必需内容超限则提示精简。停止、接口错误或解析失败保留已收到内容，未完成的结果不能直接采用；程序异常退出后，未结束轮次标为中断，可参考其内容继续生成。

改写时选择选区或当前章/片段全文。选区写入校验原位置与原文，全文改写校验生成时的全文；原文变化后需重新生成，防止覆盖后来的编辑。全文超过六万字时需分段选择打磨，避免把截断的内容当成完整改写稿。写入前保存正文快照。

## 数据与兼容

结构化总纲和卷纲存入作品 JSON；章纲仍使用 `Chapter.plan`，扩展确认元数据、卷归属与场景细纲。正文记录增加可选类型，旧记录默认为正式章节；查询分别返回章节和独立片段。规划历史使用故事专属设置键保存，完整数据库备份包含所有新增数据。

规划采用、恢复、关联调整、片段编入和章节重排使用事务。规划草稿绑定生成时的规划指纹，后续编辑后旧建议不能直接覆盖。写作与打磨的结果类型、范围、原文和规划选项随工作台草稿保存，重启后仍可审核。

旧蓝图原文完整保留，不自动猜测总纲或卷章内容；「整理旧蓝图为总纲」确认后仅产生审核建议。长篇按卷顺序及卷内章序导出，旧未分卷章节纳入第一卷；自由探索按章序导出。独立片段通过片段区单独导出。

## 本地验证

运行 `npm test` 和 `npm run build`（包含类型检查）。使用 `node scripts/qa-workspace.mjs` 启动隔离验收，打开控制台输出的长篇与探索链接。该脚本使用内存数据库、真实领域逻辑和模拟模型响应，不访问作者数据或真实付费接口，停止后测试内容消失。

规划树验收使用 `node scripts/qa-workspace.mjs --planning-tree`，注入空卷、场景细纲和故意交错的旧章序。可验证拖动整理预览、取消与确认、跨卷移动、场景排序、展开状态刷新保留，以及蓝图整理确认后只产生待审核候选。

测试覆盖确认与草稿参考、规划影响范围、恢复、分层逐项采用、过期与跨故事目标拦截、片段事实隔离、编入与版本、章序复核、数据库重开持久化及旧职责覆盖。模型的创作品质和对复杂因果的判断仍需作者审核，本次范围不包括平行剧情分支或无人值守整本生成。
