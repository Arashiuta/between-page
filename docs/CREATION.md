# 工作台创作规则

故事蓝图是唯一规划来源，包含自由分区、总纲、卷纲、章纲与场景细纲。章纲关联章节，正文记录只存正文及采用状态。手工保存与 AI 建议采用后立即生效，不再另设确认状态。

已保存蓝图优先于世界与人物；蓝图内部从全局约束向场景细化。冲突时指出需协调处，不能跨领域自动修改。候选、聊天和未来规划不属于已发生事实。

## 模式与工具

两种模式保留同一份故事内容，独立保存工具状态和对话。自由探索使用自由分区，不要求完整大纲与结局；长篇可以按需使用五种层级，任意层级可留空。共享底层服务，各模式使用独立提示、表单范围及目标校验。

| 工具     | 输入和结果                                         | 写入                   |
| -------- | -------------------------------------------------- | ---------------------- |
| 灵感脑暴 | 全部有效非正文资料与明确标注的未采用候选，自然聊天 | 仅聊天记录             |
| 完善蓝图 | 参考全部设定，只处理指定层级                       | 完整蓝图节点           |
| 开篇     | 当前空章                                           | 空章正文               |
| 续写     | 完整当前正文与衔接                                 | 只追加文末             |
| 文段打磨 | 编辑器选区、完整当前章及故事依据                   | 仅原选区               |
| 故事检查 | 方向、当前章／所选章节／全书                       | 仅报告                 |
| 记忆整理 | 当前章已采用版本                                   | 带章节及版本来源的记忆 |
| 插画构思 | 场景、设定、图片                                   | 插画提示词             |
| 章节命名 | 当前章及关联蓝图                                   | 章节名称               |

## 上下文

所有作品文字请求经过同一构建服务。完整有效设定、全部保存的蓝图、有效记忆和关联参考图进入请求。图片去重并携带所属资料标识，通过 image_url 发送；封面不自动发送。

关联参考图发送前按比例缩放至最长边 2048 像素，每张最多 1 MB，多图合计最多 3 MB（不含 Base64 编码开销）。超限图片在白色背景上转换为 JPEG，必要时继续缩小；原始素材保持不变，请求预览与来源快照保存实际发送的图片，避免大幅 PNG 导致网关拒绝请求。

人物与世界资料编辑中的 AI 提炼独立于创作工具：上传文档仅保存在当前编辑会话，完整发送勾选原文，结果填入概述、固定规则及新增分区要点。保留现有自由分区，作者检查后手动保存；原文不入库，也不保存为创作对话或来源快照。已有旧文档可在下次编辑中提炼，保存时移除原文。

从资料库引入或新建故事时选用的资料保存为带 sourceCardId 的独立只读副本。资料库后续编辑、删除不会改写副本；手工保存与 AI 采用均不能修改副本，允许移除并重新引入。故事内手工新建的资料仍可编辑。

创作工具可选择已勾选文字模型，模型优先级为本次选择、AI 职责模型、默认文字模型。模型选择按作品及模式暂存，切换模型继续同一对话，预览、生成、能力预算与结果来源使用实际选定模型。

基础资料及打磨所需完整当前章不能静默截断或摘要。超出预算、参考图不可读取、模型不支持图片输入时阻止调用。普通前文可仅保留最近两章末尾，较早对话可按完整轮次缩减，预览明确实际范围与省略情况。估算采用 UTF8 字节数作为保守文本预算，图片预留 4096 token，并预留／限制输出。

脑暴不会自动带入任何正文、正文快照或其他对话。它会带入未采用设定／蓝图候选并明确标注。故事检查逐章发送完整正文；连续性和人物弧线还对每一对所选章节发送两章完整正文。调用次数为 n 或 n+n(n−1)/2，预览逐批展示；不适合容量或篇幅的批次记录失败。报告汇总问题、来源引用、影响、建议、章节和跨章覆盖状态，不能将部分完成显示为完整。

## 差异审核与写入

TaskRequest 按工具区分目标与范围。TaskResult 分为聊天、报告、修改建议、插画提示词；前两者没有写入能力。修改建议存为 ChangeSet，前端不能传入新目标，只能选择已保存建议并编辑建议正文或名称。

统一审核显示红色删除和绿色新增，并有文字标识。按完整目标分项采用。主进程事务内检查模式、目标指纹、基础资料指纹、生成完成状态和采用状态，保存快照后更新内容并记录采用。全部剩余目标先校验，防止分项采用意外授权外部编辑。事务失败完整回滚。

文段使用 ProseMirror 文档位置与原始选区文字校验，富文本变更仅在选区范围内进行。续写保持全部原节点并追加段落。已有正文无法使用开篇写入。正文审核后仍是草稿，作者采用本章后才能提取正式事实。

对话保存实际请求来源快照、模式、工具、目标和分支。生成中断不产生可采用修改；重启后未完成轮次标记中断。删除聊天不删除独立候选。候选按领域放在对应页面，组与单条默认收起，展开状态持久化，不裁剪到固定数量。

本轮不保留旧任务、旧存储结构或迁移层。数据库结构版本为 2，旧开发数据库需使用新的空数据目录重建。
