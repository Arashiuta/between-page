# 即兴创作与逐步完善设定

本次检查以两条可以随时切换的路径为目标：只给一句话就能开始并继续故事；作者后来完善设定，后续创作遵循这些设定。

## 蓝图、设定与记忆

| 内容       | 负责的问题                               | 例子                                         |
| ---------- | ---------------------------------------- | -------------------------------------------- |
| 故事蓝图   | 作者希望接下来怎样发展，可以留空或改变   | 打算让驿站修理师在第三站揭示钥匙的来历       |
| 世界与人物 | 故事应遵守的人物特征、能力边界与世界规则 | 主角只能操纵接触过的金属                     |
| 故事记忆   | 已采用正文中实际发生了什么、谁知道什么   | 第一章拾到一把带裂纹的钥匙，主角还不知道用途 |

同一条伏笔可以同时涉及蓝图和记忆：记忆保存正文中已经出现的线索与尚未兑现的承诺，蓝图保存作者计划如何铺垫、何时回收。改变回收计划不会改写已经发生的事。临时伤势、位置和物品状态属于随剧情变化的记忆，不应变成永久的人物规则。

## 使用路径

1. 新建故事，名称可以暂时留空，只写“能操纵金属的人来到废土，开车冒险”之类的想法。自由探索默认使用「自由发挥」，也可随时切换到「适度补全」或「遵循设定」。
2. 在正文页点击「直接生成开篇」，编辑结果后追加到本章。角色资料、完整世界观、故事结局和本章计划均不是开篇的前置条件。
3. 使用「正文写作」继续当前章，或点击「让故事进入下一章」。本章计划可以留空，也可随时指定遭遇、人物变化和篇幅。未采用的前章草稿可以供续写衔接，但不会成为正式记忆。
4. 喜欢这个故事后，使用「完善设定与蓝图」。可要求细化能力、整理已有世界规则、增加聚落，或只安排下一站。新增的设定与计划按分区展示，支持编辑和逐项采用。
5. 稳定的角色、世界信息进入「世界与人物」，未来事件、人物弧线和回收安排进入「故事蓝图」。已采用正文的提炼带版本与原句依据；从草稿或 AI 补充形成的内容标为新增构想。
6. 采用后的资料进入后续写作上下文。作者可继续手工完善资料卡中的固定规则、自由分区和「始终参考」标记。详细设定与自由发挥可以结合使用，明确设定始终优先。

## 本次修正的缺口

| 原有情况                                 | 调整后                                                       |
| ---------------------------------------- | ------------------------------------------------------------ |
| 正文职责依赖本章计划，限制新增设定       | 新增即兴开篇；正文支持无计划续写，并按创作自由度补足细节     |
| 碎片整理强调忠实归纳，缺少主动发展设定   | 保留忠实整理工具，新增「完善设定与蓝图」负责主动补全         |
| 候选主要以整段文字写入一个蓝图分区       | 新增结构化分区建议，分别更新蓝图、人物或世界资料             |
| 蓝图和人物页面没有工作台                 | 故事内各页共用工作台，切页保留本次要求与结果                 |
| 生成结果缺少后续衔接                     | 支持据此完善设定与蓝图、根据结果写正文、规划结果写入本章计划 |
| 前章未采用就进入新章可能失去衔接         | 提供明确标记的前章草稿参考，不混入正式记忆                   |
| 长章节上下文只保留开头，可能漏掉最新结尾 | 保留开篇及最近正文，明确标记省略部分                         |

## 数据与扩展

- 任务种类集中在 `src/shared/types.ts` 的 `taskKinds`，IPC、草稿和流程持久化共用校验列表；新增任务不会遗漏独立枚举。
- `src/shared/tools.ts` 统一工具说明、结果类型与候选保存规则；`src/shared/roles.ts` 负责可编辑职责，`src/shared/creation.ts` 负责本故事的创作自由度。
- 设定完善以分区变更契约扩展，包含目标、追加/替换、来源和生成时的内容指纹。引用与目标在服务端校验；采用前若相关资料或来源已改变，旧提案不会直接覆盖后来的编辑。
- 分区更新与撤销记录在同一数据库事务中提交。保留资料原文、固定规则、图片和未涉及的分区。新增内容不直接写入故事记忆。
- 旧故事、既有自定义分区和职责设置继续兼容；旧故事未设置自由度时使用「适度补全」，新建自由探索默认使用「自由发挥」。

## 当前范围

设定提炼正文预算约 3.6 万字，最多读取最近 60 个有效采用章节，每章最多约 6000 字，过长时保留首尾并说明省略。还会参考有效记忆、已有资料及最近草稿；模型不能将未提供的部分宣称为已检查。较长作品仍应结合重点人物、关键词、记忆整理与连续性检查使用。

撤销针对上次采用的分区更新；如果更新后又手工编辑了相关蓝图或资料，会保留这些后续编辑并要求手动调整。正文改写继续使用既有的章节版本机制。模型对事实、因果和设定冲突的理解仍需作者判断，结构校验只验证来源与写入目标等可确定条件。
